# 微信手机连接

微信连接使用官方 iLink 二维码授权。桌面端不需要填写 App ID 或密钥，
也不会模拟登录个人微信客户端。

## 连接

1. 打开设置，保留的 `IM 接入` 入口会进入“手机连接”页面。也可以点击侧栏底部的“手机连接”。
2. 点击“连接微信”。
3. 用手机微信扫描二维码，并在手机上确认。
4. 如果手机显示数字验证码，在桌面端输入后确认。
5. 页面显示“在线”后，在微信私聊中发送文本消息。

扫码人会自动成为该连接的已授权用户。当前页面不再展示旧的配对码、
默认项目和平台密钥表单。

## 断开

点击“断开连接”会删除本机微信凭据并重启 IM sidecar。已在内存中的旧
token 不会继续运行。之后可以重新生成二维码连接另一个账号。

## 当前范围

当前第一版支持：

- 单个微信账号；
- 扫码人私聊；
- 文本消息进入现有 Gugu Session；
- Agent 文本回复返回同一微信会话；
- 重启后用本地凭据和更新游标恢复；
- 网络失败后的长轮询退避重连。

暂不承诺群聊、多账号、主动推送、图片/语音/文件和超长任务后的
`context_token` 有效性。这些能力需要单独做平台兼容和真机验证。

## 本地数据与安全

- 非敏感账号元数据：`~/.claude/adapters.json`
- 微信 bot token：`~/.claude/weixin/credentials.json`
- 消息更新游标：`~/.claude/weixin/cursor.json`

token 不会进入普通设置 API、Renderer 状态或日志。当前凭据文件使用
原子写入和 POSIX 0600 权限，但尚未接入 Windows Credential Manager /
macOS Keychain，因此这是内测存储方案，不是最终生产凭据库。

## 真机 smoke

发布前使用真实安装包完成：

1. 未连接状态生成二维码，检查二维码可扫描且五分钟后失效。
2. 扫码、确认，必要时输入验证码。
3. 页面在 sidecar 重启后显示“在线”。
4. 微信发送短文本，Gugu 收到并回复。
5. 连续发送两条消息，检查同一联系人顺序。
6. 启动一个超过三分钟的任务，检查最终回复；记录任何 token 超时。
7. 退出并重启 Gugu，再发送一条消息。
8. 断开连接，确认微信不再触发 Gugu。
9. 再次连接，确认没有重复运行两个微信通道。

真实扫码、手机确认和租户侧授权无法由自动测试代替。
