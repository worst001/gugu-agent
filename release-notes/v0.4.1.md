# Gugu Agent v0.4.1

## Highlights

- Refined the project sidebar flow so new sessions inherit the intended project context without mixing unrelated session memory.
- Improved desktop chat behavior for proactive tick replies, including cleaner message grouping and fewer distracting intermediate states.
- Added clearer capability and task-run status surfaces for provider, MCP, skills, RTK, computer-use, knowledge, and scheduled work.
- Improved keyboard shortcuts and empty-session starter actions for faster desktop navigation.

## Fixes

- Fixed proactive tick replies merging into previous assistant bubbles or exposing fork actions that should only apply to user-driven turns.
- Fixed scheduled task cleanup so one-shot tasks are finalized and disabled even when CLI startup fails.
- Fixed desktop sidecar startup so launcher environment setup happens before the bundled CLI entrypoint runs.
- Hardened session title, project removal/restore, MCP configuration, binary-file read handling, and chat recovery edge cases.

## Packaging

- Keeps bundled RTK checks in the Windows and macOS desktop packaging path.
- Updates the release runbook with the latest updater and RTK validation expectations.
