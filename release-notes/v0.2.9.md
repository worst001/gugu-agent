# Gugu Agent v0.2.9

## Fixes

- Fixed completed chat turns that could appear blank after returning to a background window; empty assistant transcript entries are filtered and truly empty completions now show a visible notice.
- Fixed pending tool permission prompts that could disappear when the app still had a pending request but the transcript did not include the permission message.
- Suppressed internal sidecar telemetry export diagnostics so they no longer surface as user-facing chat errors.
- Added clearer download safety guidance for Windows browser warnings such as "not commonly downloaded" on the official download page and in the desktop About settings.

## Notes

- This is a patch release from the `fix/bug-from-master` desktop release line after `v0.2.8`.
