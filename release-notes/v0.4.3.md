# Gugu Agent v0.4.3

## Highlights

- Re-runs the desktop release on top of the fixed macOS packaging workflow.
- Keeps the 0.4.2 desktop and gateway hardening changes while avoiding the failed 0.4.2 tag run.
- Allows macOS CI packaging to fall back to explicit ad-hoc signing when Apple Developer ID secrets are not configured.

## Fixes

- Ensures the macOS release job can continue when Apple Developer ID credentials are absent, while still warning that TCC permissions may need to be re-granted.
- Keeps Developer ID signing verification active whenever Apple signing credentials are configured.

## Packaging

- Publishes a clean 0.4.3 tag instead of moving the already-pushed 0.4.2 tag.
- Uses the existing bundled RTK and updater artifact checks.
