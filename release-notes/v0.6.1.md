# Gugu Agent v0.6.1

## New Features

- Adds QR-code connection and local runtime management for WeChat and Feishu.
- Adds a Git workbench for reviewing repository changes and focused file diffs.

## Improvements

- Improves GLM, Kimi, and DeepSeek-compatible provider behavior and Agent tool-call validation.
- Improves IM attachment handling, pairing diagnostics, and Windows path compatibility.
- Keeps WeChat conversations in the configured project directory and makes Feishu authorization safely cancellable.

## Fixes

- Preserves all existing IM adapter settings while adding the new phone connection flows.
- Prevents valid repeated streaming text from being dropped.
- Advances WeChat message cursors only after successful message handling.
- Prevents cancelled Feishu credentials from being restored by a late authorization request.
- Avoids misleading diff content when a changed file is too large to review safely.
