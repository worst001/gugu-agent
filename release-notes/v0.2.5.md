# Gugu Agent v0.2.5

## Highlights

- Improved Windows in-app updater behavior so the app exits cleanly after installing an update.
- Strengthened Office Toolbox routing for document summary, spreadsheet analysis, PPT drafting, email drafting, and file handling.
- Updated the desktop app name and window title to `Gugu Agent`, with refreshed official social links in Settings.

## Fixes

- Prevented internal observer sessions from appearing in the desktop session list or being opened from the API.
- Kept tool-use activity visible while assistant messages stream, avoiding premature status changes during long-running work.
- Added safer Office Toolbox guidance so requested output type takes priority over source file format.

## Packaging

- Added desktop release orchestration tools for versioning, artifact checks, smoke-test receipts, and OSS publish gating.
- Added updater signature validation so Windows `latest.json` and `.sig` metadata publish only the single-line Tauri public signature.
- Added a macOS updater smoke-test script for staging/local interception before promoting hot updates.
