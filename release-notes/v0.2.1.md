# Gugu Agent v0.2.1

## Highlights

- Added Office Toolbox V1 in the desktop composer, including coding, document summary, spreadsheet analysis, PPT draft, email draft, and file handling modes.
- Added a visible activity/status panel for long thinking, permission waits, and tool execution, so users can see what Gugu is currently doing.
- Improved context usage display for new sessions and failed estimates.
- Bundled the `office-suite` skill and updated the built-in MCP/plugin packaging policy for small-user-friendly defaults.

## Fixes

- Prevented Office Toolbox internal routing prompts from leaking into user bubbles, session history, and conversation titles.
- Fixed attachment-only Office Toolbox runs so internal fallback text is not shown to users.
- Added cleanup logic for old dirty Office Toolbox titles created by leaked internal prompts.
- Improved long-running task visibility around thinking, Bash, Write, permission waits, and plan mode.
- Improved subscription/quota and session recovery messaging in several user-facing error paths.

## Packaging

- Keeps local analysis output, temporary files, generated test artifacts, and desktop dev logs out of the release source snapshot.
- Desktop release is built by GitHub Actions from the `v0.2.1` tag.
- Hot update depends on the signed updater archives, matching `.sig` files, and merged `latest.json` generated and uploaded by the release workflow.
