# Gugu Agent Desktop v0.2.3

This hotfix hardens Windows MSI packaging after the 0.2.1/0.2.2 updater incident.

## Fixed

- Removed the MSI shortcut `System.AppUserModel.ID` property from Windows release artifacts to avoid the installer warning seen as `Warning 1946`.
- Stages the bundled agent skills resource from a short temporary path during desktop packaging so WiX can build the MSI without Windows path-length failures.
- Re-signs the Windows updater MSI after packaging cleanup so the `.msi.sig` file always matches the final uploaded MSI.
- Regenerates the Windows updater manifest from the final signature instead of preserving a stale `latest.json`.

## Notes

- `latest.json` must remain on the previous safe version until Windows fresh install and old-version upgrade smoke tests pass.
- Windows release validation must confirm no installer warning is shown and that `C:\Program Files\gugu-agent\gugu-agent.exe` exists after install or upgrade.
