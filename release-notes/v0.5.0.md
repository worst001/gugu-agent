# Gugu Agent v0.5.0

## Improvements

- Refreshes the desktop shell with updated visual styling, theme support, and more stable window/menu controls.
- Adds native browser and terminal workbench surfaces for browsing, console, and file workflows inside the desktop app.
- Improves sidebar, tab, capability, and workbench layouts so sessions, tools, and activity state are easier to scan.
- Expands terminal and file actions, including native open/reveal behavior and stronger settings coverage.

## Fixes

- Makes the model selector persist through the real settings path instead of a stale runtime-only override.
- Preserves automatic strong/fast task routing when no explicit model preference is supplied.
- Opens Windows workspace paths without routing through `cmd.exe /C start`.
- Tightens workbench, sidebar, terminal, and update-flow regression coverage.
