# Gugu Agent v0.4.0

## Highlights

- Added a project-grouped desktop sidebar with clearer running-session metadata.
- Added project removal and restore behavior so noisy or stale workspaces can be hidden without deleting sessions.
- Added smarter new-session working directory selection based on the active project context.
- Added desktop keyboard shortcuts for common session, search, sidebar, tab, submit, and stop actions.
- Added General settings health cards for provider, GLM, MCP, skills, RTK, computer-use, and knowledge capabilities.
- Added starter task buttons on the empty session screen.

## Fixes

- Improved chat history recovery when a session has stored messages but the in-memory transcript is empty.
- Improved error cards for permission, session, network, rate-limit, and attachment parsing failures.
- Localized managed attachment parser failures into clearer Chinese messages.
- Kept chat activity and stop-state handling consistent after assistant final states.
- Cleaned up desktop Rust warning paths without changing runtime behavior.

## Packaging

- Keeps bundled RTK validation in the desktop packaging path.
- Keeps updater and installer publishing on the existing GitHub Actions release workflow.
