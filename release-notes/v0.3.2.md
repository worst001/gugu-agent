# Gugu Agent v0.3.2

## Fixes

- Fixed the desktop release build failure caused by a floated Rust lockfile dependency set in `v0.3.1`.
- Kept the bundled RTK PATH fix from `v0.3.1` so macOS agent sessions can find app-managed `rtk`.
- Kept the long URL and long text layout fixes for chat input, message bubbles, permission details, and Markdown links.

## Packaging

- Release automation now updates only the desktop app version in `Cargo.lock` instead of regenerating the whole lockfile during version bumps.
- Restored the known-good `brotli` dependency lock combination used by the successful `v0.3.0` build.

## Notes

- `v0.3.1` did not publish artifacts because CI failed before the OSS publish step. This version replaces it as the publishable patch release.
