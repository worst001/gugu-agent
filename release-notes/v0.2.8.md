# Gugu Agent v0.2.8

## Fixes

- Fixed Windows STDIO MCP host command lookup so tools installed in common user paths, including npm global shims such as `codegraph`, can be detected and launched from the desktop app.
- Fixed a desktop chat recovery issue where returning to a window after a background run completed could show a stale or blank transcript instead of the completed result.
- Repackaged the macOS updater archive from the canonical signed app bundle and verify its sealed resources before publishing.

## Notes

- This release supersedes `v0.2.7`.
- The existing `v0.2.7` tag is not moved because its macOS updater archive failed the release gate.
