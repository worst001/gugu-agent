# Gugu Agent v0.6.2

## Improvements

- Simplifies desktop IM settings around QR-code connections for WeChat and Feishu.
- Removes the legacy manual credential forms from the desktop IM page.
- Handles provider streaming semantics by provider family instead of applying one heuristic globally.

## Fixes

- Allows IM messages to retry after transient processing failures instead of being discarded by deduplication.
- Preserves valid repeated streaming text from generic, DeepSeek, and Kimi-compatible providers.
- Correctly converts cumulative GLM streaming snapshots without duplicating prior content.
