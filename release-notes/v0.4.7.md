# Gugu Agent v0.4.7

## Highlights

- Adds the built-in OfficeFile tool for common CSV/XLSX, DOCX, and PPTX file work without requiring Python, WPS, Excel, or PowerPoint on the host.
- Adds task-aware routing for office, coding, writing, analysis, and computer-use prompts while keeping internal router scaffolding out of visible chat titles and history.
- Improves the desktop activity panel with task progress, fallback-step summaries, and session-safe progress display.

## Improvements

- Office results now show generated-file feedback with output paths, reveal/open actions, and localized labels.
- Project grouping in the sidebar can hide removed project groups without deleting local files or session history.
- The workbench can track OfficeFile outputs as generated files for preview and follow-up.
- Hidden Project Profile settings remain unavailable from normal settings navigation.

## Fixes

- Prevents task progress from one session appearing in another session's activity panel.
- Keeps OfficeFile result-card text localized in English and Chinese.

## Packaging

- Includes the OfficeFile implementation, office processors, task context graph, and release smoke checklist updates in the desktop release.
- Gateway changes are not part of this release payload.
