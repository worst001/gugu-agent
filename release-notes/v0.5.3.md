# Gugu Agent v0.5.3

## Improvements

- Persists desktop appearance, layout, projects, tabs, drafts, and per-session tool choices in app-managed profile files.
- Adds safe desktop configuration backup, import, and reset controls with private workspace data excluded by default.
- Improves desktop navigation, keyboard actions, workbench state, and durable AgentTask status and evidence views.

## Fixes

- Flushes pending drafts and profile changes before quit, window close, configuration import, and update installation.
- Restores imported tabs without stale local writes overwriting the imported workspace.
- Shares one AgentTask runtime between tool and desktop API entry points.
- Prevents multiple active AgentTasks from competing inside the same session.
