# Gugu Agent v0.4.4

## Highlights

- Adds the Office toolbox entry points to the first-session composer and keeps office-style intents consistent after a chat is active.
- Polishes the chat input, message list, empty session, and compact context presentation for a steadier desktop experience.
- Improves process shutdown, runtime prewarm behavior, and WebFetch safety before the next desktop rollout.

## Fixes

- Prevents context compaction from leaving the chat input locked if the final compact-boundary event is missing.
- Hardens stop handling for long-running CLI sessions by terminating POSIX process groups and Windows process trees.
- Restores the default managed runtime after one-turn CE fast preference and prewarm transitions.
- Avoids automatically following cross-host WebFetch redirects.
- Keeps nested hidden scaffolding out of restored chat history.

## Packaging

- Adds regression coverage for compact fallback, CLI process cleanup, runtime transitions, and chat UI behavior.
- Keeps billing/referral test totals aligned with the current managed-model quota rules.
