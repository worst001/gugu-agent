# Gugu Agent Desktop v0.2.2

This hotfix pauses the broken Windows 0.2.1 updater path and hardens future Windows updates.

## Fixed

- Windows updater no longer relaunches the app immediately after installation. The app exits after installation so the Windows installer can finish without racing the next launch.
- Windows release packaging keeps the Tauri v2 updater artifact mode aligned with the configured `createUpdaterArtifacts` behavior.

## Notes

- Windows 0.2.1 was rolled back from the live updater manifest while this fix is validated.
- Existing Windows users whose local executable was removed by the failed 0.2.1 update should use the repaired installer package once this version passes upgrade smoke testing.
