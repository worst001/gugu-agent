# Gugu Agent v0.1.19

本次版本补发语音输入与 Gugu Managed 模型路由相关改动，并修复 0.1.18 后续暴露的语音转写可用性问题。

## 新增

- 新增桌面端语音输入入口，支持录音后调用云端 ASR 将音频转写到输入框，便于长提示词口述后再编辑发送。
- 新增 `/api/audio-transcription` 服务端接口，默认对接 Bailian/DashScope 兼容模式的 `qwen3-asr-flash`。
- 新增 `/api/audio-transcription/status` 状态接口，用于桌面端在录音前判断云端转写是否可用。

## 改进

- Gugu Managed 模型槽位归一化：快速模式走 `gugu-managed-fast`，主模型、Sonnet、Opus 槽位统一走 `gugu-managed-main`，避免旧的 strong 槽位继续触发不稳定路径。
- 语音输入在云端 ASR 不可用时会优先尝试浏览器内置识别兜底；没有兜底能力时直接给出友好提示，不再让用户录完才失败。
- ASR 上游或配置错误不再原样展示给用户，界面统一显示“音频识别失败，请稍后重试”一类产品文案，详细错误仅保留在控制台日志中。

## 修复

- 修复未配置 Bailian/DashScope key 时，桌面端仍显示语音入口并在录音结束后弹出原始配置错误的问题。
- 修复云端 ASR 失败时可能把上游错误内容直接暴露到 toast 的问题。

## 验证

- 服务端 ASR 与 provider 映射测试已通过。
- 桌面端语音输入、Provider 设置相关测试已通过。
- Desktop TypeScript lint 已通过。
