# Gugu Agent v0.4.2

## Highlights

- Hardened the macOS desktop release pipeline with Developer ID signing checks when Apple credentials are configured, plus explicit warnings for ad-hoc fallback builds.
- Improved Gateway production observability for large repeated managed-model requests, order backlog health, payment integrity, and backup checks.
- Added pending-payment order cleanup tooling so expired or stale pending orders can be cancelled safely without deleting audit history.

## Fixes

- Fixed the desktop release workflow so Apple signing certificate secrets are available to the macOS build job instead of the Windows build job.
- Fixed duplicate large-request diagnostics so failed or refunded managed-model requests are marked as failed, not completed.
- Improved the desktop empty assistant result copy and preserved the original user prompt when attachment parsing produces an empty local display echo.

## Packaging

- Keeps bundled RTK validation in the Windows and macOS packaging path.
- Adds stricter macOS signing verification for Developer ID release builds and updater archives.
- Updates the desktop release runbook with Apple Developer ID and TCC permission stability checks.
