# Gugu Agent v0.4.8

## Highlights

- Adds OpenAI-compatible provider extra parameters for teams that need to tune temperature, top_p, and penalty values.
- Improves busy-session handling so a second message sent while a session is already working is rejected clearly instead of leaving a ghost user bubble.
- Refreshes the official gateway site assets used by the download and purchase pages.

## Fixes

- Keeps queued permission responses from replacing the currently visible permission request.
- Shows a clearer attachment parsing quota message when managed parser credits are exhausted.
- Ensures gateway site assets are copied into Docker deployments and keeps local preview files out of git.

## Packaging

- Includes gateway asset tracking needed by the current download/purchase pages.
- Keeps updater release validation unchanged; Windows and macOS upgrade smoke are still required before switching `latest.json`.
