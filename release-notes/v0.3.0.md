# Gugu Agent v0.3.0

## Highlights

- Bundled RTK 0.42.3 with the desktop app on Windows and macOS Apple Silicon, so normal users no longer need to install `rtk` manually.
- Improved proactive tick behavior: active follow-ups run about once per minute, pause after repeated unanswered check-ins, and hide intermediate thinking/tool progress for proactive messages.
- Hardened desktop release checks so macOS updater archives and smoke receipts must prove bundled RTK is present and working.

## Fixes

- Fixed `rtk: command not found` / exit 127 failures by injecting verified app-managed RTK into child process PATH while keeping user-writable fallback bins behind it.
- Fixed proactive tick prompts being treated like real user messages in transcript wrapping and desktop history mapping.
- Fixed chat streaming buffers so concurrent sessions cannot mix assistant deltas.
- Fixed cases where returning to a backgrounded window could lose or hide the completed assistant turn.
- Fixed provider switching so explicitly choosing the official provider can return to managed OAuth even when an older custom provider setting exists.
- Fixed browser Computer Use grants so old read-only grants are not silently upgraded while new explicit browser grants can operate normally.
- Fixed bundled skill cleanup so removed packaged skills are pruned only when they have not been user-modified.

## Packaging

- Added macOS RTK signing and updater archive validation.
- Added Windows MSI and macOS updater artifact checks for bundled RTK.
- Added stricter release smoke receipt checks for RTK version and `rtk git status`.

## Notes

- This is a minor desktop release from the `fix/bug-from-master` release line after `v0.2.9`.
