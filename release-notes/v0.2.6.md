# Gugu Agent v0.2.6

## Highlights

- Added launch offer support for Pro and Max subscription packages.
- Added referral link support in the desktop subscription settings flow.
- Improved reconnect handling so long-running agent activity is tracked more reliably.

## Fixes

- Improved agent activity status while reconnecting, streaming, and waiting on tool execution.
- Added safer filesystem permission handling around desktop-side operations.
- Preserved gateway referral codes across buy and checkout pages.

## Gateway

- Added gateway launch referral support behind `GUGU_REFERRAL_ENABLED=0` by default.
- Added referral reward storage, MySQL migration `002-referrals.sql`, and referral rollout runbook.
- Added tests for referral summaries, order referral codes, referral rewards, and billing referral proxy behavior.

## Packaging

- This release is cut from `fix/bug-from-master` after `v0.2.5`; the existing `v0.2.5` tag is not moved.
