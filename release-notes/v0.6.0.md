# Gugu Agent v0.6.0

## New Features

- Adds professional multi-agent teams with built-in role packs, workflow templates, capability-aware assignment, and durable task execution.
- Adds project knowledge views, local knowledge candidates, workspace-scoped recall, and provenance-backed evidence for AgentTask results.
- Expands the desktop workbench with Git review, file changes, task evidence, and an embedded browser with local HTML preview.
- Adds Git source installation and richer management workflows for skills and plugins.

## Improvements

- Improves AgentTask status, completion policies, recovery, and session integration across desktop and server entry points.
- Improves team creation, professional task onboarding, workspace navigation, and translated thinking presentation.
- Loads Git review details on demand and keeps large repositories responsive with bounded file metadata.

## Fixes

- Rolls back empty sessions when professional task creation fails, preserving the user's prompt and previous session.
- Restricts local preview navigation and external opening to trusted content and supported workspace files.
- Tightens desktop API origin checks and plugin request validation.
- Prevents stale Git review responses and oversized repository content from blocking the workbench.
