# Gugu Agent Desktop v0.2.4

This hotfix corrects the macOS updater archive used for in-app upgrades.

## Fixed

- Repackages the macOS updater `.app.tar.gz` from the canonical signed app bundle so upgraded apps keep a valid resource seal.
- Verifies the unpacked updater app with `codesign --verify --deep --strict` during CI before signing the updater archive.
- Regenerates the macOS updater signature after repackaging so `latest.json` points to the verified archive.

## Notes

- This release replaces the unpublished 0.2.3 hot-update path. The 0.2.3 download page installers can remain available, but the online updater should move to 0.2.4 only after fresh CI artifacts and platform smoke tests pass.
