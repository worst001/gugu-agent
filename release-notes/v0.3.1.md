# Gugu Agent v0.3.1

## Fixes

- Fixed macOS agent sessions failing to find bundled `rtk` after update by prepending the app-managed RTK directory from `GUGU_RTK_PATH` into child process `PATH`.
- Fixed long URLs and long unbroken text overflowing chat input, user message bubbles, permission details, and Markdown links.

## Packaging

- macOS Apple Silicon packaging now requires bundled RTK during sidecar build, so missing or invalid RTK fails the package before release.
- Added release checklist coverage for bundled RTK verification and post-install `rtk --version` smoke checks.

## Notes

- This patch release keeps the `v0.3.0` tag unchanged and carries the RTK PATH fix into a new desktop build.
